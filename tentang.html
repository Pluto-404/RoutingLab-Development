Tujuan Prototype

Prototype ini mendemonstrasikan alur utama RoutingLab: login demo, dashboard, materi, visualisasi, mini lab, troubleshooting, evaluasi, progress, dan monitoring guru.

Batasan

Autentikasi bukan autentikasi server. Password tersimpan di JavaScript dan hanya digunakan untuk demonstrasi. Progress memakai localStorage pada browser yang sama.

Versi Produksi

Rencana produksi menggunakan Node.js + Express, TiDB Cloud untuk basis data, Cloudinary untuk media, Render untuk hosting aplikasi, dan domain khusus.

Posisi Cisco Packet Tracer

RoutingLab tidak menggantikan Cisco Packet Tracer. Media ini menjadi pendamping untuk memahami konsep, latihan logika routing, dan troubleshooting sebelum praktik simulator sebenarnya.

Catatan keamanan: Jangan gunakan akun/password sungguhan pada prototype statis GitHub Pages.
