Tentang RoutingLab

Arsitektur dan batas penggunaan pembelajaran
Supabase Connected

Tujuan Pembelajaran

RoutingLab menyediakan materi, visualisasi, CLI Lab, troubleshooting, dan evaluasi formatif untuk melatih pemahaman static routing.

Batasan

Login menggunakan Supabase Auth. Persentase latihan disimpan di database dengan RLS, tetapi belum merupakan nilai resmi yang diverifikasi server. Skor kuis tertinggi masih lokal.

Teknologi

Frontend HTML/CSS/JavaScript, Supabase Auth + PostgreSQL untuk akun dan progres, serta rencana hosting Cloudflare Pages.

Posisi Cisco Packet Tracer

RoutingLab tidak menggantikan Cisco Packet Tracer. Media ini menjadi pendamping untuk memahami konsep, latihan logika routing, dan troubleshooting sebelum praktik simulator sebenarnya.

Catatan keamanan: Gunakan akun yang terverifikasi; jangan memasukkan secret key atau password database ke dalam file frontend.
