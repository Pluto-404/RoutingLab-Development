MISI 01 · GUIDED CLI LAB

Hubungkan Dua Jaringan

Konfigurasi static route pada R1 dan R2 hingga PC0 bisa berkomunikasi dengan PC1. Periksa status interface dan tabel routing sebelum menguji koneksi.

① Periksa interface menggunakan show ip interface brief
② Pada R1 tambahkan route menuju 192.168.2.0/24
③ Pada R2 tambahkan route balik menuju 192.168.1.0/24
④ Uji ping 192.168.2.10 melalui R1

Topologi Interaktif

Klik router untuk berpindah console
Koneksi belum diuji

Gunakan tombol Kirim Paket untuk melacak perjalanan paket.

Link antarrouter
Rute R1 → LAN2
Rute R2 → LAN1

Petunjuk Alamat

Perangkat Interface IPv4
R1 g0/0 · LAN1 192.168.1.1/24
R1 g0/1 · WAN 10.10.10.1/30
R2 g0/0 · WAN 10.10.10.2/30
R2 g0/1 · LAN2 192.168.2.1/24

Belum ada penilaian.

Status hanya menyimulasikan topologi pembelajaran ini, bukan Cisco IOS lengkap.

CLI Console
Contoh konfigurasi 
R1> enable
R1# configure terminal
R1(config)# ip route 192.168.2.0 255.255.255.0 10.10.10.2
R1(config)# end
R1# show ip route

Pada R2 gunakan network 192.168.1.0 dengan next hop 10.10.10.1. Ketik ? untuk bantuan. Tidak semua perintah Cisco didukung.
