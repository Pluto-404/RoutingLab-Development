RoutingLab Login Fit Viewport

Patch hanya mengganti css/style.css dari v4. HTML dan autentikasi tidak berubah.
Desktop >=901px dan tinggi >=520px menggunakan tinggi viewport dan penyesuaian ukuran agar tidak scroll.
Mobile/tablet serta jendela sangat pendek tetap boleh scroll agar form tidak terpotong.

Cara memasang: backup css/style.css lalu ekstrak ZIP ke folder proyek dan Replace. Refresh Ctrl+Shift+R.
