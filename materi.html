Materi Inti

Bagaimana router memilih jalur?

Router membaca alamat IP tujuan dan mencocokkannya dengan tabel routing. Jika tidak ada rute yang cocok, paket tidak dapat diteruskan.

Konsep Kunci

Router

Perangkat Layer 3 yang meneruskan paket antarjaringan berdasarkan alamat IP tujuan.

Routing Table

Daftar jaringan tujuan beserta next hop atau interface keluar yang digunakan router.

Static Routing

Rute dikonfigurasi secara manual oleh administrator. Cocok untuk jaringan kecil dan stabil.

Next Hop

Alamat IP router berikutnya yang harus menerima paket agar bergerak menuju jaringan tujuan.

Perintah Cisco IOS

R1(config)# interface g0/0 R1(config-if)# ip address 192.168.1.1 255.255.255.0 R1(config-if)# no shutdown R1(config)# interface g0/1 R1(config-if)# ip address 10.10.10.1 255.255.255.252 R1(config-if)# no shutdown R1(config)# ip route 192.168.2.0 255.255.255.0 10.10.10.2 R1# show ip route R1# ping 192.168.2.10

Urutan Belajar

1. Konfigurasi interface

Pastikan IP dan subnet mask benar, lalu aktifkan interface dengan no shutdown.

2. Tambahkan static route

Tentukan destination network, subnet mask, dan next hop.

3. Verifikasi

Gunakan show ip interface brief, show ip route, ping, dan tracert.

4. Troubleshooting

Jika ping gagal, periksa interface, IP, gateway, route, lalu route balik.
